QR-Codes pro Tisch

Statische Codes – die Links (?tisch=1, ?tisch=2, …) bleiben dauerhaft gleich, auch über mehrere Turniere hinweg, unabhängig davon, wer an welchem Tisch sitzt. Einmal ausdrucken genügt für immer. Jeder Tisch scannt seinen eigenen Code und sieht dort nur seine eigenen Spielergebnisse.
